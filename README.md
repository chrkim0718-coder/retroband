# Retro Band Player 🎸

A tiny retro-style music player where
a cute puppet band "plays" your YouTube music.

- 🎵 YouTube audio only
- 🧸 Toy-like 3D band (three.js)
- 📼 Retro, imperfect, cozy

## Tech Stack
- Next.js (App Router)
- TypeScript
- three.js
- @react-three/fiber

## Run locally

```bash
npm install
npm run dev
```

## Deploy
Optimized for Vercel.
